# Chapter 3 — Design Tool Integration
**Skills Tutor: Ioana Drogeanu**

## Overview
This chapter translates the computational analysis from Chapters 1 and 2 into 
architectural form using two software environments: Blender and TouchDesigner.
The workflow moves from AI image generation, through fragment matching, to 
word-driven 3D variations, to audio-driven real-time deformation. Each step 
extends and transforms the previous one — the datasets, the machine learning 
outputs, and the dialogue corpus all become generative inputs to the design system.

## Structure

### Fragments to Locations/
- `clip_fragment_matching.ipynb` — CLIP script matching visual fragments to 
  24 walk locations via top TF-IDF words from the dialogue corpus
- `fragment_to_location.csv` — Matching results (fragment → location → similarity score)
- `fragment_to_location.xlsx` — Same as Excel
- `LOCATIONS - TOP WORDS FROM CONVO.xlsx` — Top TF-IDF words per location (input)
- `IMAGES/` — 49 visual fragment images manually extracted from the AI-generated Turin image

### Blender/
- `blender_word_driven_system.py` — Python script for Geometry Nodes word-driven 
  variation system. 43 words from the dialogue corpus drive geometric transformations 
  across 3 categories (soft/medium/chaotic). Produces 42 architectural variations.
- `sentence_script.py` — Python script for sentence accumulation system. Input sentences 
  generated by the LSTM next-word prediction model from Chapter 1. Transformations 
  compound sequentially across each word in the sentence — the machine's language 
  becomes the building's shape.

### Touch_Designer/
- `AudioVariations.toe` — TouchDesigner network: walk location audio (sounds-18.mp3) 
  drives real-time geometric deformation of a Blender variation via RMS amplitude 
  analysis. Python script controls noise amplitude, period, flow speed and twist strength.
- `sounds-18.mp3` — Walk location audio recording (0.2MB)

## Workflow Sequence
1. AI image generation — DALL-E generates abstract reconstructions of Turin from all datasets
2. Manual fragment extraction — 49 fragments extracted from AI-generated image and photographed
3. CLIP matching — fragments assigned to 24 walk locations via cross-modal retrieval
4. First structures — Giardini Cavour + Monumental Arch assembled in Blender
5. Word-driven system — 43 dialogue words drive 42 geometric variations
6. Sentence accumulation — LSTM-generated sentences compound transformations
7. TouchDesigner — walk audio drives real-time deformation of exported Blender variation
